Day-1 : Fundamentals & Array 
----------------------------
1) Given the input array, find the indices of matching 2 sum of given two numbers.
   Ex - Array - {2,3,8,11,16,23} , num1=4, num2=7 , sum=11 exists in array return its index.

2) Given the input array, find the two indices of matching given the target.
   Ex - Array - {2,7,11,15} , target=9 , output - {0,1} exists in array return with two indices.

3) Given the sorted input array in non-decreasing/asc order, return the array of squares of each 
   number sorted in non-decreasing/asc order.

4) Given input array and the target remove the matching target from the array.
   Hint - use of Arrays.copyOf() method.
